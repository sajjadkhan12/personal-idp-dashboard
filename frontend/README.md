# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1E_fvO9181AmMW3JXR27ysk6skEn0AAyQ

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Create a `.env.local` file with the following environment variables:
   ```
   NEXT_PUBLIC_GITHUB_ORG_NAME=your-github-org-name
   NEXT_PUBLIC_API_URL=http://localhost:4000
   ```
3. Run the app:
   `npm run dev`
